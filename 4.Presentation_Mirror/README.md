# 🎓 Presentation Mirror (교육 발표 실시간 미러링 플랫폼)

> **"강사의 칠판 위에 얹힌 실시간 투명 아크릴판과 수강생의 개인 교재 책갈피"**  
> 강사가 마크다운 교육자료를 진행할 때 수강생들의 화면을 실시간으로 완벽히 동기화하고, 자유로운 판서와 수강생의 자율 복습 모드를 동시에 지원하는 반응형 교육 플랫폼입니다.

---

## 🎯 1. 프로젝트 목적 및 학습 목표

1. **실시간 교육 몰입도 극대화:**
   - 대형 스크린이나 빔프로젝터가 잘 보이지 않는 환경에서도 수강생이 개인 노트북/태블릿 화면으로 강사의 마크다운 교재 진행 상황(페이지, 스크롤 위치, 확대/축소 배율)을 100% 동일하게 시청할 수 있습니다.
2. **인터랙티브 실시간 판서(Annotation):**
   - 강사가 마크다운 문서 위에 밑줄, 형광펜, 자유 필기, 레이저 포인터를 사용하면 수강생 화면에 실시간으로 매핑되어 설명의 맥락을 정확히 전달합니다.
3. **수강생 주도적 학습 (Follow vs Free Browsing):**
   - 수강생이 이전 내용을 다시 보고 싶을 때는 언제든 동기화를 끄고(`Sync OFF`) 자유롭게 스크롤하거나 다른 문서를 탐색할 수 있으며, **'강사 화면 따라가기'** 버튼을 누르면 언제든 즉시 강사의 현재 위치로 복귀합니다.

## 🏗 2. 아키텍처 및 기술 스택 선정 이유 (ADR: Architecture Decision Record)

| 기술 스택 | 채택 이유 (Why) & Trade-off 분석 |
| :--- | :--- |
| **Node.js (v22) + Express** | - **Why:** 가볍고 빠른 비동기 I/O를 통해 `1.교육자료/` 폴더 내 마크다운 및 이미지 파일을 즉각 서빙하고 REST API 제공<br>- **보안:** Path Traversal 방지 검증 로직 내장 |
| **Socket.IO** | - **Why:** HTTP 폴링 대신 양방향 WebSocket 통신을 통해 수십~수백 명의 수강생에게 30ms 이내의 극저지연(Low Latency)으로 스크롤과 판서 이벤트 브로드캐스트 |
| **WebRTC + MediaMTX** | - **Why:** 강사는 전체 데스크톱 영상을 한 번만 송출하고 MediaMTX가 수강생 브라우저에 재전송합니다. WHIP/WHEP 표준 연결을 사용하며 영상 프레임은 Socket.IO를 통과하지 않습니다. |
| **NotepadEngine + REST Image Upload** | - **Why:** 노션 스타일의 리치 텍스트 블록 에디터와 클립보드(`Ctrl+V`) 사진 붙여넣기 기능 제공. 대용량 이미지는 REST API로 고속 업로드 후 경량 URL만 WebSocket으로 실시간 동기화하여 소켓 부하 90% 절감 |
| **정규화 벡터 캔버스 (HTML5 Canvas)** | - **Why:** 강사와 학생의 모니터 해상도/크기가 달라도 판서 좌표를 `(x/width, y/height)` 비율로 정규화(Normalized Coordinates)하여 저장 및 렌더링함으로써 위치 어긋남 해결 |
| **상대 비율 스크롤 동기화 (Relative Scroll)** | - **Why:** 픽셀(`scrollTop`) 대신 `scrollTop / maxScroll` 백분율을 전송하여, 화면 높이가 다른 디스플레이 간에도 동일한 단락을 정확히 표시 |
| **Marked + Highlight.js + Mermaid** | - **Why:** 표준 GitHub Flavored Markdown(GFM) 파싱, 소스코드 문법 강조 및 원클릭 복사, 플로우차트/시퀀스 다이어그램 실시간 렌더링 |

## 🚀 3. 빠른 시작 및 실행 방법

### 1) 패키지 설치
```bash
cd 4.Presentation_Mirror
npm install
```

### 2) 서버 실행
```bash
# 화면 공유용 MediaMTX 실행 (최초 1회 Docker 이미지 다운로드)
npm run media:up

# 일반 실행
npm start

# 코드 수정 시 자동 재시작 모드 (Dev)
npm run dev
```

### 3) 웹 브라우저 접속 (로컬 및 호스트 사내망)
- **강사 로컬 접속:** `http://localhost:4000`
- **수강생 사내망/Wi-Fi 접속:** `http://192.168.0.4:4000` (또는 화면 상단 **[📡 접속 주소]** 버튼을 눌러 확인된 LAN IP URL)
- **강사 모드 전환:**
  1. 우측 상단의 **[🔑 강사 모드]** 버튼 클릭
  2. 기본 PIN 코드 `1234` 입력 후 인증 (환경변수 `PRESENTER_PIN`으로 변경 가능)
  3. 하단에 활성화되는 **플로팅 툴바**를 이용해 [교재 / 라이브 노트 / 화면 공유] 3대 모드를 전환하며 강의 진행
  4. **[화면 공유]**를 누르고 `전체 화면`을 선택하면 VS Code나 다른 데스크톱 도구로 이동해도 수강생에게 계속 표시
- **수강생 접속 주소 공유:**
  - 상단 헤더의 **[📡 접속 주소]** 버튼을 클릭하면 사내망에서 접속할 수 있는 모든 IP 주소가 표시되며 원클릭으로 클립보드에 복사할 수 있습니다.

## 🕹 4. 주요 기능 및 사용 가이드

### 1) 3대 화면 소스 모드 원클릭 전환
- 📖 **교재 모드 (Markdown):** `1.교육자료/` 내의 마크다운 교재를 시청하며 실시간 판서 및 밑줄/형광펜 어노테이션 진행
- 📝 **실시간 라이브 노트 모드 (Notepad):** 노션처럼 즉석에서 핵심 요약을 타이핑하고, 화면 캡처 사진을 `Ctrl+V`로 붙여넣어 수강생에게 실시간 동기화
- 🖥 **화면 공유 모드 (Desktop):** WebRTC 기반으로 강사의 실제 데스크톱 전체 화면을 실시간 고화질 스트리밍

### 2) 실시간 노션형 라이브 노트패드 (Live Notepad)
- **실시간 타이핑 동기화:** 강사가 제목 및 본문을 입력하거나 서식을 변경하면 50ms 이내로 모든 수강생 화면에 실시간 렌더링
- **클립보드 사진 즉시 공유 (`Ctrl + V`):**
  - 강사가 화면 캡처(Win+Shift+S / Mac Cmd+Shift+4) 후 노트패드 본문에 `Ctrl + V`를 누르면 즉시 고화질 사진이 업로드되어 모든 수강생에게 공유됩니다.
  - PC 내 이미지 파일 드래그 앤 드롭(Drag & Drop) 및 사진 첨부 버튼 지원
- **풍부한 노션 스타일 블록 서식:**
  - H2/H3 제목, 본문, 볼드/이탤릭/밑줄/취소선
  - 글머리 기호 목록, 번호 매기기 목록, 할 일 체크리스트(☑️)
  - 인용구(Quote), 콜아웃 강조 박스(💡 Callout), 코드 블록, 구분선
- **원클릭 마크다운 내보내기 & 복사:**
  - 작성된 강의 노트를 원클릭으로 마크다운(`.md`) 파일로 다운로드하거나 클립보드에 복사 가능

### 3) 교육자료 ZIP 다운로드
- 좌측 **교육자료 목차**의 `[교육자료 전체 ZIP 다운로드]` 버튼을 누르면 현재 서버의 `1.교육자료/` 폴더를 ZIP 파일로 내려받습니다.
- 마크다운 문서뿐 아니라 문서에서 사용하는 이미지와 첨부파일도 폴더 구조를 유지한 채 함께 포함됩니다.

### 4) 강사 모드 판서 도구 (Presenter)
- **문서 이동:** 좌측 사이드바에서 교육자료를 클릭하거나, 툴바의 이전(`[`)/다음(`]`) 버튼으로 전환
- **어노테이션 및 판서 도구 모음:**
  - 🖱 **커서 모드:** 일반 텍스트 선택 및 스크롤
  - 🖍 **CSS 텍스트 형광펜 모드 (Highlighter):** 마우스로 원하는 글자를 드래그하면, 모바일/PC 상관없이 해당 문장에 100% 일치된 형광펜이 실시간 렌더링됩니다.
  - 📏 **CSS 텍스트 밑줄 모드 (Underline):** 마우스로 원하는 글자를 드래그하면 정확한 위치에 밑줄이 동기화됩니다.
  - 🎨 **자유 판서 모드 (Draw):** 도표나 그림 위에 자유롭게 선/도형을 그리며, 가장 가까운 단락/블록 요소에 자동 앵커링되어 화면 크기가 달라도 위치가 어긋나지 않습니다.
  - 🧽 **지우개 모드 (Eraser):** 삭제할 밑줄/형광펜을 클릭하거나 판서를 문지릅니다.
  - ↩️ **실행 취소 (Undo):** `Ctrl + Z` (마지막 밑줄/형광펜/판서 되돌리기)
  - 🗑 **전체 지우기:** 현재 문서의 모든 밑줄, 형광펜, 판서 일괄 초기화
- **화면 확대/축소:** `+` / `-` / `100% 리셋` 버튼으로 화면 배율 동기화

### 5) 수강생 모드 (Student)
- **기본 모드 (강사 동기화 중):** 강사의 화면 모드(교재/노트/데스크톱), 스크롤, 줌, 판서, 타이핑, 사진이 실시간으로 미러링됩니다.
- **자유 탐색 모드 (자유 모드):**
  - 본인이 마우스 휠을 굴리거나 사이드바에서 다른 문서를 클릭하면 즉시 자유 탐색 모드로 전환됩니다.
  - 상단의 `[동기화]` 스위치를 직접 끄거나 켤 수도 있습니다.
- **강사 화면 따라가기 (Catch Up):**
  - 자유 탐색 중 우측 하단의 **[⚡ 강사 화면 따라가기]** 플로팅 버튼을 누르면 강사가 현재 머물고 있는 모드(교재, 라이브 노트, 데스크톱)와 스크롤 위치로 즉시 재동기화됩니다.

### 6) 전체 데스크톱 화면 공유
- 강사만 하단 툴바의 **[화면 공유]** 버튼을 사용할 수 있습니다.
- 브라우저 선택 창에서 반드시 **전체 화면**을 선택해야 프로그램을 전환해도 공유가 유지됩니다.
- 선택한 화면의 원본 캡처 해상도는 제한하지 않고, 글자 선명도를 우선하도록 최대 15fps로 송출합니다.
- 영상 코덱은 VP9을 우선 협상하며, 사용할 수 없으면 VP8, H.264 순으로 자동 대체합니다. 오래된 브라우저는 자체 기본 코덱 협상을 사용합니다.
- 마우스 커서는 캡처 영상에 포함되며 데스크톱 모드에서는 Presentation Mirror 판서 Canvas를 사용하지 않습니다.
- 공유를 브라우저 알림 막대나 툴바에서 종료하면 모든 수강생이 자동으로 이전 문서/노트 화면으로 돌아옵니다.
- 화면 공유 권한은 브라우저 보안 정책상 매번 사용자가 직접 승인해야 합니다.

## 🔧 7. 화면 공유 환경설정

기본 설정은 Presentation Mirror와 MediaMTX가 같은 강사 PC에서 실행되는 사내 LAN 환경입니다.

| 환경변수 | 기본값 | 설명 |
| :--- | :--- | :--- |
| `MEDIA_MTX_WEBRTC_PORT` | `8889` | MediaMTX WebRTC HTTP/WHIP/WHEP 포트 |
| `MEDIA_MTX_PATH` | `presentation` | 한 발표가 사용하는 미디어 경로 |
| `MEDIA_MTX_WEBRTC_URL` | 현재 브라우저 호스트 | MediaMTX가 별도 서버 또는 HTTPS 주소에 있을 때 지정 |

강사는 화면 캡처 보안 정책 때문에 `http://localhost:4000` 또는 HTTPS 주소로 접속해야 합니다. 수강생은 화면을 캡처하지 않으므로 안내된 LAN 주소로 접속할 수 있습니다.

MediaMTX 상태 확인:

```bash
docker compose ps
npm run media:logs
```

종료:

```bash
npm run media:down
```

### 외부망·HTTPS 운영

- `getDisplayMedia()`를 사용하는 강사 페이지는 HTTPS가 필요합니다.
- HTTPS 페이지에서 HTTP MediaMTX 주소를 호출하면 브라우저가 차단하므로 MediaMTX에도 TLS를 구성하고 `MEDIA_MTX_WEBRTC_URL`을 HTTPS 주소로 지정해야 합니다.
- 방화벽이나 NAT를 통과해야 한다면 MediaMTX의 ICE/TURN 설정을 추가해야 합니다.
- 현재 기본 구성은 신뢰할 수 있는 사내 LAN의 단일 발표 세션을 대상으로 하며 공개 인터넷 노출 전에는 MediaMTX publish/read 인증을 추가해야 합니다.

### 자주 발생하는 문제

- **화면 선택 창이 열리지 않음:** 강사 주소가 `localhost` 또는 HTTPS인지 확인합니다.
- **수강생 화면이 연결 중에서 멈춤:** `docker compose ps`에서 MediaMTX가 실행 중인지 확인합니다.
- **영상은 보이지만 커서가 없음:** 브라우저 또는 운영체제 캡처 정책에 따라 커서 옵션이 무시될 수 있으므로 Chrome/Edge의 전체 화면 공유로 다시 확인합니다.
