# 2026 아이치-나고야 아시안게임 KBS 공식 포털 웹사이트

KBS 공식 방송사(Official Broadcaster) 스타일의 **2026 아이치-나고야 아시안게임 특별 웹사이트** 프로젝트입니다.

---

## 📸 프로젝트 특징

- **KBS 공식 헤더 & GNB**
  - 최상단 유틸리티 메뉴 (About KBS, 시청자센터, 편성표, 언어 선택 등)
  - KBS 공식 로고 + 2026 아이치-나고야 아시안게임 파트너 엠블럼
  - `아이치-나고야 아시안게임` 활성 탭 인디케이터
  - 실시간 깜빡임 효과의 **`● ON AIR`** 생중계 버튼
  - 상단 드롭다운 통합 검색창 (인기 키워드 태그 포함)

- **아시안게임 시그니처 히어로 배너**
  - 바이올렛/퍼플 그라디언트 및 기하학적 아시안게임 패턴 배경
  - 상단 리본 메달 그래픽 및 **대한민국 실시간 메달 순위 위젯**
  - 위젯 클릭 시 **국가별 메달 종합 순위표 팝업**

- **하이라이트 영상 인터랙티브 캐러셀**
  - 남자 사브르 단체 "어펜져스 어셈블"
  - 한국 수영 모먼트 다 모았다!
  - 2026 아시안게임 야구 키플레이어는?!
  - 여자 양궁 리커브 신궁 10점 릴레이
  - 슬라이드 좌우 이동, 마우스 드래그 & 터치 스와이프 지원, 비디오 플레이어 모달 연동

- **주요 경기일정 섹션 (다크 네이비 테마)**
  - 날짜별 탭 (9.9 ~ 9.13) 및 종목 필터링 (대한민국, 생중계, 메달 결정전)
  - 펜싱·야구 실시간 스코어 및 LIVE 상태 배지
  - KBS 1TV / 2TV / my K 중계 채널 정보 안내

## 🛠 기술 스택

- **HTML5** (시맨틱 웹 구조)
- **Vanilla CSS3** (Flexbox, CSS Grid, Glassmorphism, CSS 애니메이션)
- **Vanilla JavaScript** (ES6+, 무의존성 가벼운 인터랙션)
- **Pretendard Font** (KBS 고유 타이포그래피 구현)

---

## 🚀 실행 방법

웹 브라우저(Chrome, Edge 등)에서 `index.html`을 직접 열거나, 로컬 서버를 통해 실행할 수 있습니다:

```bash
# Python 내장 서버로 실행 시
python -m http.server 8080
```
브라우저에서 `http://localhost:8080`으로 접속하여 확인합니다.
