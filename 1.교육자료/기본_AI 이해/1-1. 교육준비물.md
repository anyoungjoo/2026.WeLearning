## 📦 공통 준비 항목 요약

1. **개발 편집기**: Antigravity IDE 설치 및 Google 계정 로그인
2. **버전 관리 및 코드 저장소**: Git, GitHub CLI (`gh`), GitHub 계정 생성 및 연동
3. **실행 엔진**: Python 3, Node.js LTS
4. **실습 코드**: `2026.WeLearning` 프로젝트 Clone
5. **(선택 권장)**: OpenRouter API 키 발급 및 `opencode` CLI 설치

> 💡 **참고**: 각 세부 설치 방법, 원클릭 설치 명령어, 터미널 설정 및 오류 해결법은 위의 OS별 가이드에 상세히 안내되어 있습니다.
