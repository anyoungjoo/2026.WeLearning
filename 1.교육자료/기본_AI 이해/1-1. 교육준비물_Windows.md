# 1️⃣ PowerShell 스크립트 실행 정책 변경 🔴 필수

PowerShell의 기본 보안 설정에 따라 Python 가상환경의 활성화 스크립트(`Activate.ps1`)나 npm의 일부 스크립트 실행이 차단될 수 있습니다. 교육 중 발생할 수 있는 실행 정책 오류를 예방하기 위해 현재 사용자(`CurrentUser`) 범위를 `RemoteSigned`로 설정합니다.

> 💡 **안내:** `CurrentUser` 범위 설정은 시스템 전체를 건드리지 않으므로 **관리자 권한이 필요하지 않습니다.** 일반 터미널/PowerShell 창에서 바로 실행하시면 됩니다.

1. 윈도우 시작 버튼 우클릭 → **"터미널"** 또는 **"PowerShell"** 실행
2. 아래 명령어를 복사하여 붙여넣고 `Enter`를 누릅니다:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```

3. (선택 점검) 설정이 정상 반영되었는지 확인하려면 다음 명령어를 입력합니다:

```powershell
Get-ExecutionPolicy -List
```
- `CurrentUser` 항목이 **`RemoteSigned`** 로 표시되면 정상 완료입니다.

# 2️⃣ Git for Windows & Git Bash 설치 🔴 필수

코드 버전 관리 도구이자, Windows 환경에서 표준적인 Unix 터미널 환경을 제공하는 **Git Bash**를 설치합니다.

1. **[Git for Windows 공식 다운로드](https://git-scm.com/download/win)** 페이지에 접속합니다.
2. **"Click here to download the latest 64-bit version of Git for Windows"** (최신 v2.55.x) 링크를 클릭하여 설치 파일(`.exe`)을 내려받습니다.
3. 다운로드된 설치 파일을 실행합니다.
   - 대부분 기본값(Next)으로 진행하시면 됩니다.
   - **Editor 선택 화면**: 기본값(Vim) 또는 VS Code 등 선호하는 에디터 선택
   - **Adjusting your PATH environment**: **`Git from the command line and also from 3rd-party software`** (기본 권장값) 확인 후 진행
4. 설치가 완료되면 마침(Finish)을 누릅니다.

> 💡 **Git Bash 안내**:  
> Git for Windows와 함께 설치되는 **Git Bash**를 사용하면, 가상머신(WSL) 없이도 `ls`, `cd`, `mkdir -p`, `curl` 등 익숙한 Unix 계열 명령어 대부분을 Windows에서도 유사한 방식으로 편리하게 사용할 수 있습니다.

# 4️⃣ Git 기본 환경 설정 & 줄바꿈 정책 🔴 필수

Windows(`CRLF`)와 Linux/macOS(`LF`)의 줄바꿈 문자 차이로 인해 발생할 수 있는 Git 충돌을 예방하고, 커밋 작성자 정보를 등록합니다.

윈도우 시작 메뉴에서 **Git Bash**를 열고 아래 명령어를 입력합니다:

```bash
# 1) Windows 줄바꿈 자동 변환 설정
git config --global core.autocrlf true

# 2) 사용자 이름 및 이메일 등록 (본인 정보로 수정하여 입력)
git config --global user.name "내이름"
git config --global user.email "내이메일@example.com"
```

> 🛡️ **저장소 레벨의 줄바꿈 보장 (`.gitattributes`)**:  
> 본 교육 실습 저장소(`2026.WeLearning`) 루트에는 이미 `.gitattributes` 파일이 내장되어 있습니다 (`* text=auto eol=lf`). 따라서 수강생 각자의 로컬 PC 설정 차이와 무관하게 모든 코드 파일이 일관된 `LF` 줄바꿈으로 자동 통일되어 협업 충돌을 원천 차단합니다.

# 8️⃣ GitHub 계정 연동 (`gh auth login`) 🔴 필수

GitHub CLI를 사용하여 브라우저에서 원클릭으로 인증을 완료합니다.

> ⚠️ **중요:** 앞서 도구들을 새로 설치했으므로, **기존에 열려 있던 터미널 창을 모두 닫고 새로 Git Bash를 엽니다.**

새 **Git Bash** 창에서 아래 명령어를 한 줄로 복사하여 실행합니다:

```bash
gh auth login --hostname github.com --git-protocol https --web --clipboard
```

1. 명령어를 실행하면 브라우저 인증을 위한 **8자리 일회용 코드**가 클립보드에 자동 복사되고 기본 브라우저 창이 열립니다.
2. 터미널에서 `Enter`를 누르고, 열린 브라우저 창에 복사된 코드를 붙여넣은 뒤 **Authorize github**를 클릭합니다.
3. 인증이 완료되면 Git Bash에서 상태를 확인합니다:

```bash
gh auth status
```
- `Logged in to github.com account [내아이디]` 메시지가 뜨면 정상 연동된 것입니다.

# 9️⃣ 교육 실습 자료 내려받기 (Clone) 🔴 필수

> 📢 **지금부터 진행되는 모든 실습 터미널 명령어는 Git Bash를 기준으로 실행합니다.**

실습 프로젝트를 내 컴퓨터의 작업 디렉토리(`~/projects`)로 내려받습니다.

**Git Bash**에서 다음 명령어를 순서대로 실행합니다:

```bash
# 1) 사용자 홈 디렉토리에 projects 폴더 생성 및 이동
mkdir -p ~/projects
cd ~/projects

# 2) 교육 실습 저장소 복제 (정확한 URL 입력)
git clone https://github.com/gkisanet/2026.WeLearning.git

# 3) 프로젝트 폴더로 이동
cd 2026.WeLearning

# 4) (선택) 윈도우 탐색기로 해당 폴더 열기
explorer .
```

> 🪟 **윈도우 탐색기 경로 확인**:  
> 파일 탐색기 주소창 기준 `C:\Users\[내 계정명]\projects\2026.WeLearning` 폴더에 교재 및 실습 파일들이 정상적으로 들어있는지 확인합니다.

# 🔟 Antigravity 프로젝트 열기 & Workspace Rules 등록 🔴 필수

Antigravity IDE에서 실습 프로젝트를 열고, 일관된 코딩 지침을 에이전트에 주입하는 **Workspace Rule**을 활성화합니다.

### 1) 프로젝트 열기
1. **Antigravity IDE**를 실행합니다.
2. 상단 메뉴 **File → Open Folder...** 선택
3. `C:\Users\[내 계정명]\projects\2026.WeLearning` 폴더를 선택하고 **폴더 선택**을 클릭합니다.

### 2) Workspace Rule 활성화
> 💡 **규칙 연동 구조 (Single Source of Truth)**:  
> 본 저장소는 OpenCode가 참조하는 표준 지침(`AGENTS.md`)과 Antigravity 전용 작업 규칙(`.agents/rules/`)을 유기적으로 연동합니다. Antigravity의 규칙 파일이 `AGENTS.md`를 참조하므로, 두 도구가 언제나 동일한 교육 지침을 준수합니다.

1. 오른쪽 **Agent 패널** 상단의 **`…` (더보기)** 메뉴 → **Customizations** 클릭
2. **Rules** 탭 선택 → **Workspace Rules** 영역 확인
3. 프로젝트 내 `.agents/rules/course-rules.md` (또는 등록된 규칙)의 활성화 모드를 **`[ Always On ]`**으로 설정합니다.

# 1️⃣1️⃣ (옵션) OpenRouter 가입 및 API 키 발급 🟡 선택 권장

OpenRouter는 Claude, GPT, Gemini, DeepSeek 등 전 세계 주요 최신 AI 모델을 단 하나의 API 키로 유연하게 호출할 수 있는 통합 게이트웨이 서비스입니다.

1. **https://openrouter.ai** 접속 → Google 또는 GitHub 계정으로 로그인
2. 상단 메뉴 **Keys** → **Create Key** 클릭
3. **Key Name** 입력 (예: `welearning-agent`)
4. 💡 **과다 청구 방지 안전 팁 (Spending Limit)**:  
   키 생성 옵션 중 **Credit limit**에 `$5.00`를 입력하여 설정합니다. 에이전트 실습 중 실수로 무한 루프가 돌더라도 설정된 한도를 초과하지 않아 안심할 수 있습니다.

# 1️⃣2️⃣ (옵션) OpenCode 윈도우 네이티브 설치 🟡 선택 권장

터미널에서 직접 파일 생성 및 코드 리팩토링을 수행하는 오픈소스 CLI AI 에이전트 도구입니다.

> 💡 **실습 환경 안내**:  
> OpenCode 공식 문서는 Windows CLI 환경에서 WSL 사용을 가장 좋은 환경으로 권장하고 있습니다. 하지만 본 교육에서는 환경 구성의 단순화와 Windows 파일 탐색기와의 원활한 파일 접근성을 위해 **Windows 네이티브 방식(Desktop 또는 npm)**을 채택하여 실습합니다.

### 방법 A. 데스크톱 앱 (가장 권장)
- **[OpenCode 공식 다운로드](https://opencode.ai/download)** 페이지에서 Windows용 설치 파일(`.exe`)을 내려받아 설치합니다.
- *(참고: 데스크톱 앱 구동을 위해 Windows의 Microsoft Edge WebView2 Runtime이 필요하며, Windows 10/11 기본 탑재 상태가 아닐 경우 설치가 안내됩니다.)*

### 방법 B. Git Bash 터미널 CLI 버전
- 터미널에서 Node.js의 `npm` 명령어로 전역 설치합니다:
```bash
npm install -g opencode-ai
```

설치 완료 후 터미널에 `opencode`를 입력하고, `/connect` 명령어로 OpenRouter를 선택한 뒤 발급받은 API 키를 연결합니다. (종료 명령: `/exit`)

## 🚑 자주 묻는 질문 및 문제 해결 (FAQ)

### Q1. `python`을 입력했는데 Microsoft Store가 열립니다.
- 윈도우 설정 → **앱** → **고급 앱 설정** → **앱 실행 별칭**에서 `python.exe`와 `python3.exe` 항목을 **"끔(Off)"**으로 변경한 후 새 터미널 창을 엽니다.

### Q2. PowerShell에서 스크립트 실행 제한(`PSSecurityException`) 에러가 뜹니다.
- 본 가이드의 1번 단계(`Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force`)를 실행했는지 확인합니다.
- 만약 회사/기관 PC에서 그룹 정책(GPO)으로 인해 변경이 거부된다면, `Get-ExecutionPolicy -List` 명령어로 상위 정책(`MachinePolicy` 등)이 강제되어 있는지 확인하고 사내 IT 부서에 스크립트 실행 예외를 요청해야 합니다.

### Q3. 명령어를 입력했는데 `command not found`가 뜹니다.
- 환경변수(PATH) 갱신을 위해 **기존 터미널 창을 완전히 닫고 새로 열어야** 합니다. 그래도 안 될 경우 해당 도구 설치 시 "Add to PATH" 항목을 누락했는지 확인하고 재설치합니다.

### Q4. Antigravity 다운로드 사이트에서 무엇을 받아야 할지 헷갈립니다.
- 상단의 `Antigravity 2.0`이 아닌, 페이지 아래쪽의 **`Antigravity for IDEs → Antigravity IDE (Standalone) Windows x64`**를 다운로드하셔야 코드 편집기와 Agent 대화창을 정상적으로 이용하실 수 있습니다.

### Q5. OpenCode 실행 시 WebView2 관련 오류가 발생합니다.
- Windows 구버전 환경의 경우 Microsoft 공식 사이트에서 **"Evergreen Bootstrapper" (Edge WebView2 Runtime)**를 다운로드하여 설치해 주시면 정상 실행됩니다.
