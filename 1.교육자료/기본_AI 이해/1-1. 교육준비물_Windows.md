# 🧰 교육 준비물 — Windows 최신 환경 설정 가이드

> **문서 목적**: 교육 첫날 시작과 동시에 바로 실습할 수 있도록, 교육 전 Windows PC에 필요한 개발 도구와 계정을 준비하는 가이드입니다.
> 
> **⚠️ 본 문서는 교육 전에 반드시 완료하고 오셔야 합니다.**
> 사전에 미리 설치를 완료해 두셔야 당일 실습 시간에 지장 없이 참여하실 수 있습니다.

---

## ⏱️ 소요 시간 및 기본 안내

- **예상 소요 시간**: 약 20~30분
- **권장 사양**: Windows 10 (64bit) 또는 Windows 11 / RAM 8GB 이상 (16GB 권장)
- **실습 환경 안내**: 본 교육은 가상머신(WSL)을 쓰지 않고, **Windows 순수 네이티브 환경**에서 진행합니다.
  - 내 코드가 윈도우 파일 탐색기(`C:\Users\...`)에 그대로 저장되어 눈으로 바로 확인하고 더블클릭으로 열 수 있습니다.
  - 패키지 관리자의 버전 충돌이나 레지스트리 에러를 방지하기 위해 **가장 최신의 공식 검증 인스톨러(Official Installer) 방식**을 기본으로 안내합니다.

# 1️⃣ PowerShell 스크립트 실행 정책 변경 🔴 필수

윈도우는 기본 보안 정책상 파이썬 가상환경이나 개발용 스크립트 실행이 차단되어 있습니다. 이를 먼저 허용해 주어야 이후 오류가 발생하지 않습니다.

1. 윈도우 시작 버튼 우클릭 → **"터미널(관리자)"** 또는 **"PowerShell(관리자)"** 실행
2. 아래 명령어를 입력하고 `Enter`를 누릅니다:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

3. 실행 정책 변경 확인 질문이 나오면 **`A`** (모두 예)를 입력하고 `Enter`를 누릅니다.

# 2️⃣ Git for Windows & Git Bash 설치 🔴 필수

코드 버전 관리 도구이자, 윈도우에서 리눅스 명령어를 가볍고 완벽하게 사용할 수 있는 **Git Bash**를 설치합니다.

1. **[Git for Windows 공식 다운로드](https://git-scm.com/download/win)** 페이지에 접속합니다.
2. **"Click here to download the latest 64-bit version of Git for Windows"** 링크를 클릭하여 설치 파일(`.exe`)을 내려받습니다.
3. 다운로드된 설치 파일을 실행합니다.
   - 대부분 기본값(Next)으로 진행하시면 됩니다.
   - **Editor 선택 화면**이 나오면 선호하는 에디터 또는 기본값(Vim 또는 VS Code) 선택
   - **Adjusting your PATH environment** 화면에서 **`Git from the command line and also from 3rd-party software`** (기본 권장값) 확인 후 진행
4. 설치가 완료되면 마침(Finish)을 누릅니다.

> 💡 **Git Bash의 장점**:  
> Git for Windows를 깔면 함께 설치되는 **Git Bash**를 사용하면, 무거운 WSL 없이도 `ls`, `cd`, `mkdir -p`, `curl` 등 리눅스/맥과 100% 동일한 터미널 명령어를 윈도우에서 그대로 쓸 수 있습니다.

# 3️⃣ GitHub CLI (`gh`) 설치 🔴 필수

복잡한 Personal Access Token을 매번 만들 필요 없이, 웹 브라우저 팝업 클릭 한 번으로 GitHub 로그인을 연동해 주는 도구입니다.

1. **[GitHub CLI 공식 다운로드](https://cli.github.com/)** 페이지 접속
2. **"Download for Windows"** 버튼을 클릭하여 `.msi` 설치 파일을 내려받습니다.
3. 설치 파일을 실행하여 설치를 완료합니다.

# 4️⃣ Git 기본 환경 설정 🔴 필수

윈도우(`CRLF`)와 맥/리눅스(`LF`)의 줄바꿈 차이로 생기는 코드 충돌을 방지하고, 본인의 커밋 서명 정보를 등록합니다.

윈도우 시작 메뉴에서 **Git Bash** 또는 **PowerShell**을 열고 아래 명령어를 입력합니다:

```bash
# 윈도우 줄바꿈 자동 변환 설정
git config --global core.autocrlf true

# 사용자 이름 및 이메일 등록 (본인 정보로 수정)
git config --global user.name "내이름"
git config --global user.email "내이메일@example.com"
```

# 5️⃣ Python 최신 안정 버전 설치 🔴 필수

데이터 처리 및 AI 자동화 스크립트에 필요한 파이썬을 설치합니다.

1. **[Python 공식 다운로드](https://www.python.org/downloads/)** 페이지 접속
2. 노란색 **"Download Python 3.12.x"** (또는 최신 안정 버전) 버튼을 클릭하여 설치 파일을 내려받습니다.
3. 다운로드된 `python-3.x.x-amd64.exe` 파일을 실행합니다.
4. ⚠️ **가장 중요한 체크포인트**:  
   설치 첫 화면 맨 아래에 있는 **`[✓] Add python.exe to PATH`** 체크박스를 **반드시 체크**합니다!
5. 상단의 **"Install Now"**를 클릭하여 설치를 완료합니다.

### ⚠️ 마이크로소프트 스토어 실행 방지 설정 (필수 점검)
윈도우 기본 설정 때문에 `python` 입력 시 스토어 창이 뜨는 현상을 방지합니다:
1. 윈도우 설정 → **앱** → **고급 앱 설정** → **앱 실행 별칭** (또는 시작 메뉴에서 '앱 실행 별칭' 검색)
2. 목록에서 **`python.exe`** 및 **`python3.exe`** 두 항목을 모두 **"끔(Off)"**으로 설정합니다.

# 8️⃣ GitHub 가입 및 브라우저 로그인 연동 🔴 필수

### 1) GitHub 계정 가입
1. **https://github.com** 접속 → **Sign up**
2. 이메일 인증을 완료하고 계정을 생성합니다.

### 2) 브라우저 원클릭 연동 (`gh auth login`)

> ⚠️ 도구들을 설치했으므로 **열려 있던 모든 터미널 창을 닫고, 새로 Git Bash 또는 PowerShell 창을 엽니다.**

새 터미널 창에서 아래 명령어를 실행합니다:

```bash
gh auth login
```

질문이 나타나면 방향키와 Enter로 선택합니다:
1. **What account do you want to log in to?** → `GitHub.com`
2. **What is your preferred protocol for Git operations?** → `HTTPS`
3. **Authenticate Git with your GitHub credentials?** → `Y`
4. **How would you like to authenticate GitHub CLI?** → `Login with a web browser`
5. 터미널에 표시되는 **8자리 일회용 코드**를 복사하고 `Enter`를 누릅니다.
6. 자동으로 열린 브라우저 창에 코드를 붙여넣고 **Authorize github**를 누르면 로그인이 완료됩니다.

# 9️⃣ 교육 실습 자료 내려받기 (Clone) 🔴 필수

실습 프로젝트를 내 컴퓨터의 작업 폴더로 내려받습니다.

터미널(Git Bash 또는 PowerShell)에서 아래 명령어를 실행합니다:

```bash
# 1) 사용자 홈 디렉토리에 projects 폴더 생성 및 이동
mkdir -p ~/projects
cd ~/projects

# 2) 교육 저장소 복제
git clone https://github.com/gkisanet/2026.WeLearning.git

# 3) 실습 폴더로 이동
cd 2026.WeLearning
```

> 🪟 **윈도우 탐색기 확인**:  
> 파일 탐색기를 열고 `내 PC > C: > 사용자(Users) > [내 계정명] > projects > 2026.WeLearning` 폴더로 들어가 실습 파일들이 정상적으로 들어있는지 확인합니다.

# 🔟 (옵션) OpenRouter 가입 및 API 키 발급 🟡 선택 권장

OpenRouter는 GPT, Claude, Gemini, DeepSeek 등 다양한 최신 AI 모델을 하나의 키로 사용할 수 있는 AI 게이트웨이 서비스입니다.

1. **https://openrouter.ai** 접속 → Google 또는 GitHub 계정으로 로그인
2. 상단 메뉴 **Keys** → **Create Key** 클릭
3. 키 이름을 입력(예: `welearning`)하고 **Create** 클릭
4. 화면에 표시되는 긴 API 키(`sk-or-v1-...`)를 복사하여 개인 메모장에 안전하게 보관합니다. (창을 닫으면 다시 확인할 수 없습니다)
5. (선택 권장) **Credits** 메뉴에서 $5(약 7,000원) 내외 소액을 충전해 두시면 교육 기간 동안 최고급 모델들을 충분히 실습할 수 있습니다.

> 🔒 **보안 주의사항**: API 키는 신용카드 번호와 같습니다. 절대로 깃허브 공개 저장소에 올리거나 타인에게 공유하지 마세요.

# 1️⃣1️⃣ (옵션) opencode 윈도우용 설치 🟡 선택 권장

터미널에서 직접 대화하며 코드를 생성·수정할 수 있는 2세대 CLI AI 에이전트 도구입니다.

### 방법 A. 데스크톱 앱 (추천)
- **[OpenCode 공식 다운로드](https://opencode.ai/download)** 페이지에서 Windows용 설치 파일(`.exe`)을 내려받아 설치합니다.

### 방법 B. 터미널 CLI 버전
- 터미널에서 Node.js의 `npm` 명령어로 전역 설치합니다:
```bash
npm install -g opencode-ai
```

설치 후 OpenRouter 키를 연동하려면 터미널에 `opencode`를 입력하고, `/connect` 명령어로 OpenRouter를 선택한 뒤 발급받은 API 키를 붙여넣습니다. (종료는 `/exit`)

# 1️⃣2️⃣ Antigravity에서 프로젝트 열기 및 규칙 등록 🔴 필수

1. **Antigravity IDE**를 실행합니다.
2. 상단 메뉴 **File → Open Folder...** 선택
3. `C:\Users\[내 계정명]\projects\2026.WeLearning` 폴더를 선택하고 **폴더 선택** 클릭
4. 오른쪽 **Agent 패널** 상단 **`…`** 메뉴 → **Customizations** 클릭

6. 프로젝트 루트에 있는 `AGENTS.md` 내용을 확인하고 활성화(Activation) 설정을 **`[ Always On ]`**으로 지정합니다.

## 🚑 자주 묻는 질문 및 문제 해결 (FAQ)

### Q1. `python`을 입력했는데 마이크로소프트 스토어가 열립니다.
- 윈도우 설정의 **'앱 실행 별칭'**에서 `python.exe`와 `python3.exe`를 **"끔(Off)"**으로 변경해 주세요.

### Q2. PowerShell에서 스크립트 실행 불가(`PSSecurityException`) 에러가 발생합니다.
- 관리자 권한 PowerShell에서 `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`를 실행하고 `A`를 누르세요.

### Q3. 명령어를 입력했는데 `command not found`가 뜹니다.
- 설치 후 **기존 터미널 창을 닫고 완전히 새로 열어야** 윈도우 환경변수(PATH)가 갱신됩니다.
