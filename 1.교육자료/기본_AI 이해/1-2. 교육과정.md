# 📘 AI와 함께 만드는 업무 자동화 — 교육 계획서
### 부제: 바이브 코딩(Vibe Coding) 기초부터 웹 배포까지

> **과정 개요**: 생성형 AI를 단순히 질문·답변용으로 쓰는 단계를 넘어, AI와 대화하며 내 업무에 필요한 작은 자동화 도구를 직접 만들고 배포하는 6시간 실습 과정입니다.

---

## 🧭 1. 교육 소개

### 생성형 AI 활용의 전환
생성형 AI의 활용 방법은 다양합니다. 이미지·영상·텍스트를 직접 생성할 수도 있고, 기존 사내 시스템에 AI API를 탑재할 수도 있습니다.

본 교육에서는 그중 **AI를 이용해 업무에 필요한 작은 도구를 직접 만드는 방법, 즉 바이브 코딩(Vibe Coding)**을 다룹니다.

프로그래밍 문법을 밑바닥부터 외우는 것이 목적이 아닙니다.  
업무 흐름을 가장 잘 아는 실무자가 **AI와 자연어로 대화하며 코드를 생성하고, 실행 결과를 테스트·피드백하며 내 업무에 맞는 자동화 도구를 직접 완성하는 협업 방법**을 익힙니다.

### 왜 바이브 코딩인가?
실무를 하다 보면 개발팀에 정식 프로젝트로 요청하기에는 작지만, 매주 반복되어 많은 시간을 소모하는 작업들이 있습니다.

- 매주 반복되는 Excel 데이터 정리 및 취합
- 사내 ERP 및 웹 시스템의 단순 반복 입력
- 여러 분산된 자료의 교차 조회 및 형식 변환
- 부서 내에서 함께 쓰는 간단한 업무 점검 도구

과거에는 직접 프로그래밍을 배우거나 개발 외주를 맡겨야 했지만, 이제는 AI 코딩 도구를 통해 **현업 담당자가 자신의 PC에서 직접 작은 자동화 도구를 구현할 수 있는 환경**이 마련되었습니다.

### AI 활용 방식의 3가지 차이

| 방식 | 대표 예시 | 주요 특징 및 고려사항 | 본 교육의 위치 |
| :--- | :--- | :--- | :---: |
| **① AI가 결과물을 생성** | 이미지, 홍보 영상, 기사 초안, 자막 | 창의적 작업에 유리하나, 정보의 정확성을 사람이 전량 검토해야 함 | 배경 이해 |
| **② 시스템에 AI 기능을 탑재** | AI 챗봇, 문서 자동 분류기, AI Agent | 업무 편의성은 높으나, 지속적인 API 비용·보안 심의·오답 모니터링 체계 필요 | 발전 과제 |
| **③ AI로 업무 도구 제작 (바이브 코딩)** | Excel 자동화, Chrome Extension, 사내 웹앱 | **AI는 제작 과정의 개발 보조자로만 활용**하고, 완성된 도구는 로컬에서 정해진 규칙대로 동작 | **⭐ 본 교육의 핵심** |

이번 과정에서는 완성된 프로그램 안에서 AI를 실시간 호출하기보다, **도구를 만드는 과정에서 AI를 보조 개발자로 활용하는 방식**을 중점적으로 다룹니다. 완성된 도구는 내 컴퓨터에서 규칙 기반으로 안전하게 실행되며, 실무 데이터는 사본을 이용해 사전 검증합니다.

> 📄 **더 깊은 배경 논증이 궁금하시다면**:  
> 왜 AI를 시스템 안에 바로 넣지 않고 도구 제작부터 시작해야 하는지, 기술적·운영적 고민과 트레이드오프는 **「[1-3. 왜_바이브코딩인가.md](./1-3.%20왜_바이브코딩인가.md)」**에서 상세히 다룹니다.

## ⏱️ 3. 교육 개요

- **과정명**: AI와 함께 만드는 업무 자동화 — 바이브 코딩 기초부터 웹 배포까지
- **교육 대상**: 프로그래밍 경험이 없거나 적은 직장인 / 업무 자동화가 필요한 실무자
- **교육 시간**: **총 6시간 (3시간 × 2일)**
- **실습 환경**: Windows / macOS 네이티브 환경 (Antigravity IDE, Git, Python 3, Node.js)

### 왜 6시간 중 절반을 "Context 관리"에 쓰는가?
AI와 장시간 코딩을 진행하다 보면 **"처음에는 잘 만들다가, 대화가 길어질수록 앞서 내린 지침을 잊거나 코드를 엉뚱하게 되돌리는 현상"**을 겪게 됩니다.

이는 AI의 성능 문제가 아니라, 대화가 누적되면서 **AI가 한 번에 읽을 수 있는 작업 기억 공간(Context Window)에 중요한 지침이 밀려나기 때문**입니다.  
1일차에서는 이 Context 한계를 체계적으로 통제하고 관리하는 실무 표준 기법(`AGENTS.md`, 인수인계 문서화 등)을 확실하게 훈련합니다.

## 📦 5. 교육 후 만들 수 있는 것들

- **반복 문서 자동화**: 정기적으로 반복되는 엑셀 데이터 취합·정리 도구

- **팀 협업 소형 웹앱**: 팀원들과 공유하여 사용하는 가벼운 현황 조회 및 점검 웹페이지

- **자립적 개발 역량**: 교육 이후 새로운 업무 문제가 생겼을 때, 혼자서 AI와 대화하며 도구를 설계하고 검증할 수 있는 능력
