# 🧰 교육 준비물 — macOS 환경 설정 가이드

> **문서 목적**: 교육 첫날 시작과 동시에 바로 실습할 수 있도록, 교육 전 Mac(macOS) 장비에 필요한 개발 도구와 계정을 준비하는 가이드입니다.
> 
> **⚠️ 본 문서는 교육 전에 반드시 완료하고 오셔야 합니다.**
> 도구 다운로드 및 설정에는 시간이 소요되므로, 사전에 미리 완료해 두어야 원활한 교육 참여가 가능합니다.

---

## ⏱️ 소요 시간 및 사전 확인

- **예상 소요 시간**: 약 15~20분
- **지원 환경**: Apple Silicon (M1 / M2 / M3 / M4) 및 Intel Mac 모두 지원
- **준비물**: 터미널(Terminal) 앱 실행 권한, 안정적인 인터넷 연결

# 1️⃣ Xcode Command Line Tools 설치 🔴 필수

macOS에서 각종 개발 도구를 구동하고 컴파일하는 기본 도구 모음입니다.

`Spotlight (Cmd + Space)`에서 **터미널(Terminal)**을 검색하여 실행한 뒤 아래 명령어를 입력합니다:

```bash
xcode-select --install
```

> 팝업 창이 나타나면 **"설치"** 버튼을 클릭하고 약 2~5분간 대기합니다. (이미 설치되어 있다는 메시지가 나오면 다음 단계로 넘어갑니다)

---

# 2️⃣ Homebrew 패키지 매니저 설치 🔴 필수

Mac에서 필수 개발 도구를 가장 안정적이고 깔끔하게 설치·관리해 주는 도구입니다.

터미널 창에 아래 한 줄을 복사하여 붙여넣고 `Enter`를 누릅니다:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

설치 도중 Mac 사용자 암호를 물어보면 키보드로 입력 후 `Enter`를 누릅니다. (화면에 글자가 보이지 않는 것은 정상 보안 동작입니다)

> ⚠️ **Apple Silicon (M1/M2/M3/M4) Mac 필수 안내**:  
> 설치 완료 시 터미널 화면 마지막에 나오는 **Next steps** 안내를 따라 아래 두 명령어를 차례대로 실행해야 합니다:
> ```bash
> echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
> eval "$(/opt/homebrew/bin/brew shellenv)"
> ```

---

# 3️⃣ Git 및 GitHub CLI (`gh`) 설치 🔴 필수

코드 버전 관리 도구인 **Git**과 브라우저 원클릭 로그인을 지원하는 **GitHub CLI (`gh`)**를 설치합니다.

터미널에서 아래 명령어를 실행합니다:

```bash
brew install git gh
```

---

# 4️⃣ Git 기본 환경 설정 🔴 필수

협업 시 줄바꿈 충돌을 방지하고 커밋 작성자 정보를 등록합니다.

터미널에 아래 명령어를 순서대로 입력합니다:

```bash
# macOS 줄바꿈 표준 설정
git config --global core.autocrlf input

# 사용자 이름 및 이메일 등록 (본인 정보로 변경)
git config --global user.name "내이름"
git config --global user.email "내이메일@example.com"
```

# 7️⃣ Antigravity IDE 설치 🔴 필수

본 교육의 메인 실습 환경인 에이전틱 AI 코딩 IDE를 설치합니다.

1. **https://antigravity.google/download** 접속
2. **macOS** 버전 (Apple Silicon 또는 Intel) 다운로드
3. 다운로드된 `.dmg` 파일을 열고, Antigravity 아이콘을 **Applications(응용 프로그램)** 폴더로 드래그합니다.
4. Launchpad 또는 응용 프로그램에서 Antigravity를 실행하고 본인의 **Google 계정으로 로그인**합니다.
5. 화면 오른쪽에 AI 에이전트 대화 패널이 뜨는지 확인합니다.

# 8️⃣ GitHub 가입 및 로그인 🔴 필수

### 1) GitHub 계정 가입
1. **https://github.com** 접속 → **Sign up**
2. 화면 안내에 따라 이메일 인증을 완료하고 계정을 생성합니다.

### 2) 터미널에서 브라우저 원클릭 연동 (`gh auth login`)

터미널에서 아래 명령어를 실행합니다:

```bash
gh auth login
```

질문이 나오면 방향키와 Enter로 선택합니다:
1. **What account do you want to log in to?** → `GitHub.com`
2. **What is your preferred protocol for Git operations?** → `HTTPS`
3. **Authenticate Git with your GitHub credentials?** → `Y`
4. **How would you like to authenticate GitHub CLI?** → `Login with a web browser`
5. 터미널에 표시되는 **8자리 코드**를 복사하고 `Enter`를 누릅니다.
6. 자동으로 열린 브라우저 창에 코드를 붙여넣고 **Authorize github**를 클릭하면 완료됩니다.

# 9️⃣ 교육 실습 자료 내려받기 (Clone) 🔴 필수

실습 프로젝트를 내 Mac의 작업 폴더로 내려받습니다.

터미널에서 아래 명령어를 순서대로 실행합니다:

```bash
# 1) 홈 디렉토리에 projects 폴더 생성 및 이동
mkdir -p ~/projects
cd ~/projects

# 2) 저장소 복제
git clone https://github.com/gkisanet/2026.WeLearning.git

# 3) 실습 폴더로 이동
cd 2026.WeLearning
```

> 🍏 **Finder 확인**:  
> Finder를 열고 `홈 > projects > 2026.WeLearning` 폴더로 이동하여 실습 소스코드와 교재들이 정상적으로 내려받아졌는지 확인합니다.

# 🔟 (옵션) OpenRouter 가입 및 API 키 발급 🟡 선택 권장

OpenRouter는 다양한 최신 AI 모델(Gemini, Claude, GPT, 오픈소스 모델)을 하나의 키로 사용할 수 있는 AI 서비스입니다.

1. **https://openrouter.ai** 접속 → Google 또는 GitHub 계정으로 로그인
2. 상단 메뉴 **Keys** → **Create Key** 클릭
3. 키 이름을 입력(예: `welearning`)하고 **Create** 클릭
4. 화면에 표시되는 API 키(`sk-or-v1-...`)를 복사하여 개인 메모장에 안전하게 보관합니다. (창을 닫으면 다시 확인할 수 없습니다)
5. (선택) **Credits** 메뉴에서 $5 내외 소액을 충전해 두시면 교육 기간 동안 다양한 모델을 충분히 테스트할 수 있습니다.

> 🔒 **보안 주의사항**: API 키는 신용카드 번호와 같습니다. 절대로 깃허브 공개 저장소에 올리거나 타인에게 공유하지 마세요.

# 1️⃣1️⃣ (옵션) opencode 맥용 설치 🟡 선택 권장

터미널이나 GUI 화면에서 직접 대화하며 코드를 생성·수정할 수 있는 2세대 AI 에이전트 도구입니다.

### 방법 A. 데스크톱 앱 (추천)
- **[OpenCode 공식 다운로드](https://opencode.ai/download)** 페이지에서 macOS용 설치 파일(`.dmg`)을 내려받아 응용 프로그램 폴더로 이동합니다.

### 방법 B. 터미널 CLI 버전
터미널 창에서 아래 명령어로 설치합니다:

```bash
curl -fsSL https://opencode.ai/install | bash
# 또는 npm으로 설치
npm install -g opencode-ai
```

설치 후 OpenRouter 키를 연동하려면 터미널에 `opencode`를 실행하고, 대화창에서 `/connect` 입력 후 **OpenRouter**를 선택하여 발급받은 API 키를 입력합니다. (종료: `/exit`)

# 1️⃣2️⃣ Antigravity에서 프로젝트 열기 및 규칙 등록 🔴 필수

1. **Antigravity IDE**를 실행합니다.
2. 상단 메뉴 **File → Open Folder...** 선택
3. `~/projects/2026.WeLearning` 폴더를 선택하고 열기를 클릭합니다.
4. 오른쪽 **Agent 패널** 상단 **`…`** 메뉴 → **Customizations** 클릭
5. **Rules** 탭 → **`+ Workspace`** 클릭
6. 프로젝트 루트에 있는 `AGENTS.md` 내용을 확인하고 활성화(Activation) 설정을 **`[ Always On ]`**으로 지정합니다.

```bash
git --version
```

| 검증 명령어 | 정상 출력 예시 | 조치 사항 |

모든 버전이 정상 출력되면 교육 준비가 완료되었습니다! 수고하셨습니다.

## 🚑 자주 묻는 질문 및 문제 해결 (FAQ)

### Q1. `brew` 명령어를 입력했는데 `command not found: brew` 오류가 뜹니다.
- **원인**: Apple Silicon Mac에서 Homebrew 경로가 쉘 설정 파일에 등록되지 않은 경우입니다.
- **해결법**: 터미널에 아래 두 줄을 실행하고 터미널을 다시 엽니다:
  ```bash
  echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
  eval "$(/opt/homebrew/bin/brew shellenv)"
  ```

### Q2. Antigravity 실행 시 "확인되지 않은 개발자가 배포했기 때문에 열 수 없습니다" 경고가 뜹니다.
- **해결법**: Mac **시스템 설정 → 개인정보 보호 및 보안**으로 이동하여 화면 아래쪽의 **"확인 없이 열기"** 버튼을 클릭합니다.

### Q3. 회사 Wi-Fi에서 `brew` 설치나 저장소 복제 속도가 너무 느립니다.
- **해결법**: 사내 보안망 영향일 수 있으므로, 모바일 핫스팟(테더링) 또는 자택 네트워크 환경에서 사전 설치를 진행해 주시기 바랍니다.
